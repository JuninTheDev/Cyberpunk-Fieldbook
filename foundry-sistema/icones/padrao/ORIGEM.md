# Ícones padrão do CORE

Os SVGs desta pasta são cópias sem alteração de `icons/compendium/default/` do sistema **Cyberpunk RED - CORE
v0.92.4**, de **The Project Red Team**, distribuído como GPL v3. A fonte de referência neste repositório é
`cyberpunk-red-core/`; o projeto original é <https://gitlab.com/cyberpunk-red-team/fvtt-cyberpunk-red-core>.

Os nomes dos arquivos foram conservados. O Fieldbook não depende de o CORE estar instalado: estes arquivos seguem
com o sistema. Drogas e upgrades usam o ícone de equipamento, que é o padrão desses tipos no `GetDefaultImage` do CORE.
