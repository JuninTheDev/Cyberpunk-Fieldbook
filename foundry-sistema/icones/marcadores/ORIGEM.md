# Marcadores de turno do CORE 0.93

Os SVGs desta pasta são cópias sem alteração de `src/icons/hud/turn-marker_*.svg` do sistema **Cyberpunk RED - CORE**
na versão de desenvolvimento 0.93, de **The Project Red Team**, distribuído como GPL v3. A fonte de referência neste
repositório é `fvtt-cyberpunk-red-core-dev/`; o projeto original é
<https://gitlab.com/cyberpunk-red-team/fvtt-cyberpunk-red-core>.

Os nomes dos arquivos foram conservados. A configuração "Marcador de turno" do sistema (o C43, parte 2) escolhe entre
eles, como o "Token Marker" do CORE 0.93.
